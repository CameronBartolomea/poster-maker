# Strategic Home Loans — Brand Assets

Reusable assets for every SHL flyer/poster. Reference them from posters with
relative paths, e.g. `../assets/brand/logo/shl-logo-full-color.png`.

## brand/logo/
- `shl-logo-full-color.png` — primary logo, house+puzzle icon with full
  "Strategic Home Loans / Financing that fits perfectly" wordmark. Transparent
  background. Use this as the default logo on light backgrounds.
- `shl-logo-compact.png` — square icon+wordmark version, good for small
  placements (corner badges, social avatars, business cards).
- `shl-logo-small.jpg` — low-res web-size logo (144x72). Avoid for print.
- `shl-logo-wordmark-red.png` — text-only "STRATEGIC Home Loans" wordmark in
  red, no house icon, transparent-trimmed. Use when the icon is already
  present elsewhere on the page and you just need the wordmark.
- `shl-logo-source.pdf` — original source file as provided, kept for
  reference/re-export at any resolution.

Brand colors (from company profile): red `#c72108`, charcoal `#474747`,
white used subtly.

## brand/badges/
- `equal-housing-opportunity.png` — required Equal Housing Opportunity logo.
  Include on any flyer that advertises loan products or an open house,
  typically small, bottom corner, near the NMLS/license disclosures.
