# Asset Manifest

## Brand assets used (all genuine, pulled from the repo's verified set)
- `assets/brand/logo/shl-logo-full-color.png` -- official SHL logo,
  used on both sides of both versions
- `assets/brand/badges/equal-housing-opportunity.png` -- Equal Housing
  Opportunity badge, used on both sides of both versions
- `assets/brand/qr/qr-cameron-vcard.png` -- Cameron's vCard QR, back
  side of Cameron's version only
- `assets/brand/qr/qr-robert-vcard.png` -- Robert's vCard QR, back
  side of Robert's version only

No headshot was used on either side -- the brief allowed one "when
appropriate," and this piece is a conversation reference card, not a
personal-brand flyer, so a headshot would have competed with the
educational content for attention without adding function. Flagging
this as a deliberate choice, not an oversight, in case Cameron wants
one added.

## Typography
Outfit (Google Fonts), the single approved family, weights 300-900,
no second typeface introduced.

## Color palette
Only colors from `design-system/tokens.css`: brand red (#c72108),
charcoal (#474747), near-black (#262626), the standard neutral
tints/shades. No new color introduced.

## Data source
All personal and company fields (names, titles, NMLS, DRE, phone,
email, office address) come from `data/people.json`, injected via
`scripts/render-person-flyer.js` -- never hand-typed into the template,
which is what the automated cross-contamination checking actually
verifies against.

## Original artwork
The front's visual system (the escalating three-band composition and
accent-bar motif) is original work built for this piece, not a
template, stock graphic, or AI-generated image. No clip art or
decorative icon set was used anywhere on either side.
